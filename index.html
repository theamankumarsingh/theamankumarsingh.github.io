BugsInDLLs

2025

A benchmark of reproducible bugs in deep learning libraries. Each bug in PyTorch, TensorFlow, or JAX is packaged as a per-bug test case with an isolated environment (Python, Conda, Docker), so the failure reproduces consistently. Its run-tool command runs a testing tool, such as FreeFuzz, inside a bug's environment to check whether the tool can reproduce it. BugsInDLLs contains 112 reproducible bugs, addressing the lack of standardized benchmarks for evaluating testing and fuzzing tools.

Indoor Navigation System

2024

Locates a user indoors from WiFi signal strength. A Python pipeline collects and preprocesses WiFi RSSI readings, which Gaussian Bayes, Decision Tree, and KNN classifiers use to predict the user's room, and a Flutter app serves the prediction. The models reached 87% accuracy, 0.91 precision, and 0.88 F1 score for room-level location prediction.

Lumos

2021

An offline, real-time accessibility app for visually, hearing, and speech impaired users. On-device TensorFlow/Keras models (TFLite) provide object and currency detection and colour identification, and American Sign Language (ASL) recognition lets speech- and hearing-impaired users communicate with people who do not know sign language. Every result is spoken through text-to-speech, and large touch targets with distinct vibrations on each screen make navigation easy without sight. Built at HackMIT 2021, organized by the Massachusetts Institute of Technology.
